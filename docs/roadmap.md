# Roadmap

## Shipped in 0.1.0

- Engine-neutral timeline compilation and EngineContract 1.0–1.2, frame-clock
  take transactions, receipts, verified media assembly, resumable capture, and
  aspect-aware shot alternatives.
- Unity integration: scene roles, isolated offline presentation, Film Inspector,
  independent example, and local Workbench entry point.
- Three.js integration: generic/TypeScript stages, fresh-browser workers,
  seeded hooks, role-bounds review, measurement, and numeric expectations.
- Godot integration: pure-GDScript addon, scene declarations, read-only editor
  dock, owned supervisor, fresh workers, review/measure/expect workflow, and
  standalone addon ZIP. Godot 4.6 or newer (tested on 4.6.2); native acceptance
  covers macOS arm64 standard and Mono, not every advertised platform.
- CLI, stdio MCP, and authenticated local Workbench share the same compiler,
  film documents, production service, and capability boundaries.

See [production](production.md), [Godot](godot.md), and [installation](install.md).

## Next engine: Unreal

Unreal is not implemented. The next integration must declare stable roles/assets,
admit only executable capabilities, own presentation state and cleanup, and prove
installation, restart, frame stepping, capture, and source freshness on a real
project. It must use the existing contract rather than copy Core semantics.

## Planned distribution channels

Current releases provide platform archives, Unity tarballs, and Godot addon ZIPs.
Publication to **npm**, the **Godot Asset Library**, and **OpenUPM** is planned;
none is an available installation channel yet.

## Further validation and authoring

- Native clean-machine coverage on more operating systems, GPUs, and renderers.
- More real project onboarding trials; portable project/media transfer.
- Richer performance authoring, voice/lip-sync, and resource budgets.
- Contain fitting and FilmPlan variants; continuous human audiovisual review
  remains distinct from numeric regression and sampled composition checks.

## Non-goals

GameDirector directs presentation, not gameplay truth. Arbitrary live gameplay,
remote/non-loopback bridges, and unbounded realtime control are not promised.
